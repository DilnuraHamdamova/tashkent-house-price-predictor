# Data source and redistribution notice

## Source and provenance

`data/apartment_listings_2026.csv` is an independently collected, privacy-minimized snapshot of
public Tashkent apartment-sale listing pages on [HATA.uz](https://hata.uz/). It is not an official
HATA dataset, API export, partnership, or endorsement.

The snapshot retains factual fields needed for this educational regression project: listing ID
and date, district, rooms, area, apartment floor, building floors, building type, advertised USD
asking price, source URL, and collection timestamp. It excludes seller names, contact details,
free-text descriptions, and images.

## Rights and permitted-use warning

HATA's public terms do not present this catalog as openly licensed data. HATA and listing authors
may retain rights in the website, catalog, and listing content. This repository therefore does not
grant any license to HATA content and does not claim ownership of the underlying listings.

The committed snapshot exists for transparent educational review and reproducibility of this
portfolio project. Before redistributing the snapshot, using it commercially, refreshing it at
scale, or building a production service from it, review the current
[HATA Terms of Use](https://hata.uz/en/terms) and obtain any permission your use requires.

If redistribution permission is not available, keep the snapshot private and publish only code,
aggregate statistics, trained artifacts where permitted, and instructions that require an
authorized user to supply their own data.

## Model output boundary

The target is an advertiser's asking price, not a verified completed transaction price. The model
is an educational comparison tool, not an appraisal, lending decision, tax valuation, or price
guarantee.

This notice documents provenance and known uncertainty; it is not legal advice.
